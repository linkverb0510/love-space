# Local Visual Assets

All visual assets are shipped locally. The application never loads an image from a third-party host at runtime.

## Materials

- `materials/cotton-jersey-diffuse-cc0.jpg` - **Cotton Jersey** diffuse texture by colormass and Rico Cilliers, [Poly Haven source](https://polyhaven.com/a/cotton_jersey), **CC0 1.0**. It is used as a low-contrast physical textile lining behind the pink paper surfaces; the source image itself is unchanged.

Poly Haven assets are released under [CC0 1.0](https://polyhaven.com/license).

## Character Stickers

The `characters` directory remains intentionally empty until the couple approves character assets. No private reference photo is stored in this repository.

## Couple Mascots

- `brand/mascot-l.svg`, `brand/mascot-w.svg` - original hand-drawn Q-version mascots of the couple, drawn in-repository from their reference photo. No photographic likeness is shipped; the reference photo itself lives outside version control (`local-assets/` is git-ignored). Released under **CC0 1.0** by the site owners.
