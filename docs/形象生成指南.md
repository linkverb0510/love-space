# 双人形象生成指南(AI 头像)

网站里的头像走**私密通道**:你在外部图片 AI 生成两张写实动漫风头像 → 本地脚本上传到 Supabase 私有存储 → 登录私密空间后自动显示。公开页面永远不会出现真人头像。

## 第一步:生成头像

把你们的合照一起上传给图片 AI(即梦、豆包、ChatGPT 等)当参考图,然后分别用下面两条提示词生成。提示词已按合照里的真实特征写好,可直接复制。

**L 的头像(男生):**

```text
参考这张合照,只画其中的男生,不要出现其他人。
日系写实动漫风格半身头像插画,正常头身比例和真实五官比例,
不要Q版、不要大头娃娃、不要夸张变形。
严格保留他的真实特征:黑色蓬松自然卷发(头顶卷曲明显、有光泽感)、
浓黑的平眉、温和的双眼皮眼睛、开朗的露齿微笑、健康白皙的肤色、
方正偏圆的脸型。
他穿着一件海蓝色翻领衬衫,扣子扣好。
头部微微右转呈四分之三侧面,看向镜头微笑。
构图到胸部以上,人物居中,纯奶油米色干净背景,
柔和均匀的正面光,细腻干净的线条,轻小说封面般的温暖上色质感。
方形 1:1 画面。
```

**W 的头像(女生):**

```text
参考这张合照,只画其中的女生,不要出现其他人。
日系写实动漫风格半身头像插画,正常头身比例和真实五官比例,
不要Q版、不要大头娃娃、不要夸张变形。
严格保留她的真实特征:黑色长直发姬发式造型(整齐的齐刘海,
两侧长直发垂落到胸前)、大而温柔的双眼皮眼睛、精致小巧的鹅蛋脸、
恬静温柔的微笑、白皙皮肤。
她穿着粉色洛丽塔连衣裙,外搭一件白色雪纺小开衫,
头上戴粉色荷叶边发带并在侧面系一个小蝴蝶结,和合照里那套一样。
头部微微左转呈四分之三侧面,看向镜头温柔微笑。
构图到胸部以上,人物居中,纯浅粉色干净背景,
柔和均匀的正面光,细腻干净的线条,少女漫画封面般的温柔上色质感。
方形 1:1 画面。
```

**实用技巧**

- 一定把合照作为**参考图/垫图**上传;即梦里选「人像保持」类参考,强度调高;
- 一次只生成一个人,像不像多抽几张挑最好的;
- 生成结果如果偏Q版,补一句「请按真实人头比例,头身比约1:7,不要可爱化变形」;
- 背景务必纯色,圆形裁切才好看;
- 需要的话让 AI 顺手把背景换成浅蓝(L)/浅粉(W)呼应网站配色。

## 第二步:整理文件

把两张图存成 PNG(或 JPG),放进项目的 `local-assets` 文件夹:

```
local-assets/l-avatar.png
local-assets/w-avatar.png
```

`local-assets` 目录已被 .gitignore 保护,**永远不会被提交到仓库**。

## 第三步:上传(一次性)

项目里已准备好 `.env.local`(含 Supabase 配置,被 gitignore 保护)。用编辑器打开项目根目录的 `.env.local`,在末尾补一行你的共享密码:

```
AVATAR_SHARED_PASSWORD=你们的私密空间密码
```

保存后运行(Git Bash / macOS / Linux):

```bash
node --env-file=.env.local scripts/upload-avatars.mjs local-assets/L.png local-assets/W.png
```

Windows PowerShell 则分两步:

```powershell
$env:AVATAR_SHARED_PASSWORD="你们的私密空间密码"
node --env-file=.env.local scripts/upload-avatars.mjs local-assets/L.png local-assets/W.png
```

看到两条 `✓ 已上传` 即成功。**打开私密空间刷新页面**,顶栏身份按钮和首页「海蓝色的 L / 粉色的 W」角色卡就会显示头像。

## 想换头像?

重新生成 → 再跑一次上传脚本即可(同名覆盖)。头像以签名链接加载,只在登录后的私密空间有效,链接一小时自动过期,不会泄露。
