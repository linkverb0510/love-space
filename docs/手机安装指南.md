# 手机安装指南 · 把「Our Little Space」装成手机 App

不需要应用商店,也不用付费开发者账号——它是一个 PWA,手机浏览器自带的「添加到主屏幕」功能就能把它变成桌面图标,点开全屏运行,和原生 App 几乎一样。

开始前,先在浏览器打开你们的私密空间链接:

```
https://linkverb0510.github.io/love-space/?space=private
```

输入共同密码登录一次(登录态会记住,以后一般不用再输)。

---

## iPhone / iPad(Safari)

1. 用 **Safari** 打开上面的链接并登录;
2. 点屏幕底部中间的**分享按钮**(方框加向上箭头);
3. 在菜单里找到并点**「添加到主屏幕」**,确认图标名字,点右上角「添加」。

完成后桌面会出现粉色拍立得图标,点开即是全屏私密空间。

> 注意:请务必用 Safari 操作,Chrome on iOS 的添加体验不完整。

## Android(Chrome / Edge)

1. 用 **Chrome** 打开上面的链接并登录;
2. 点右上角 **⋮ 菜单**;
3. 点**「添加到主屏幕」**或**「安装应用」**,确认即可。

部分手机会在页面底部直接弹出「添加到主屏幕」的横幅,点一下即可。

---

## 常见问题

**Q:图标点开是空的只读页面?**
说明链接少了 `?space=private`。从主屏幕删除图标,用上面带参数的完整链接重新添加一次(安装好的 App 本身已直达私密空间,正常情况不会遇到)。

**Q:过一段时间打开要求重新输密码?**
系统的隐私策略偶尔会清理网页登录态,重新输一次共同密码即可,内容不会丢。

**Q:如何删除?**
和删除普通 App 一样长按图标删除;这只移除入口,云端内容仍然安全保留。

**Q:两个人同时编辑会冲突吗?**
不会。系统按条目做了版本保护,另一台设备保存的内容会自动同步过来;极少数同时改同一条时会提示刷新。

**Q:电脑上能装吗?**
可以。Edge / Chrome 打开私密链接后,地址栏右侧会出现「安装」图标,点击后它会以独立窗口运行。
