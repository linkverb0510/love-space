# Character Sticker Handoff

These prompts are intentionally about the people rather than the website. Use a private, high-quality couple photo as the strict visual reference in the external image model, then review every output before placing it in `public/assets/characters`.

## Shared prompt

Create a delicate anime illustration sticker based strictly on the supplied couple reference photo. Preserve both people's real facial features, hairstyles, hair colors, clothing, accessories, body proportions, height difference, and affectionate relationship. Keep the same clothing and accessories from the reference photo; do not redesign their outfits. Use clean fine linework, soft natural shading, restrained detail, subtle print grain, and a natural off-white die-cut sticker border. Transparent background, isolated figures, polished 2048x2048 PNG, no text, no logo, no watermark, no background, no extra people, no fantasy clothing, no themed costume change, no flat geometric avatar style.

## Variants

- `couple-sticker.png`: both people together, relaxed intimate pose, readable full figures, suitable for the home welcome panel.
- `l-half.png`: L alone, half-body identity pose, same reference clothing and accessories.
- `l-action.png`: L alone, small natural action pose, full or three-quarter figure, same reference clothing and accessories.
- `w-half.png`: W alone, half-body identity pose, same reference clothing and accessories.
- `w-action.png`: W alone, small natural action pose, full or three-quarter figure, same reference clothing and accessories.

## Negative prompt

Do not add Lolita clothing, gothic costume, ribbons that are not in the reference, crowns, fantasy props, new jewelry, extra characters, text, lettering, logos, watermark, scenery, colored background, cropped face, changed hairstyle, changed clothing, exaggerated body proportions, plastic 3D rendering, or simplistic geometric avatar shapes.
