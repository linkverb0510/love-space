# 双人形象生成指南(AI 头像)

网站里的头像走**私密通道**:你在外部图片 AI 生成两张写实手绘风头像 → 本地脚本上传到 Supabase 私有存储 → 登录私密空间后自动显示。公开页面永远不会出现真人头像。

## 第一步:生成头像

把你们的合照上传给任意图片 AI(即梦、ChatGPT、豆包等),分别生成 L 和 W 的单人头像。可直接复制以下提示词(把括号内容换成实际特征):

**L 的头像:**

> 参考这张合照,画出其中(男生/女生)的半身头像:写实但可爱的手绘插画风格,类似轻文艺绘本上色,柔和的水彩质感;保留真实发型(黑色短发)、脸型与五官神韵,戴(黑框眼镜);穿着(常穿的衣服);微微微笑,看向镜头;干净的奶油色纯色背景;正面构图,头部居中,方形 1:1 画面,风格温暖治愈。

**W 的头像:**

> 参考这张合照,画出其中(女生/男生)的半身头像:写实但可爱的手绘插画风格,类似轻文艺绘本上色,柔和的水彩质感;保留真实(长发/发型)与五官神韵;穿着(常穿的衣服);温柔微笑,看向镜头;干净的浅粉色纯色背景;正面构图,头部居中,方形 1:1 画面,风格温暖治愈。

**小贴士**

- 一张一张生成,提示词里的特征描述越具体越像;
- 生成后如果不像,补一句「更接近照片里的五官比例」重试;
- 背景一定要纯色,方便圆形裁切好看。

## 第二步:整理文件

把两张图存成 PNG(或 JPG),放到好找的位置,例如:

```
C:\Users\李世旺\Desktop\Temp\LOVE\local-assets\l-avatar.png
C:\Users\李世旺\Desktop\Temp\LOVE\local-assets\w-avatar.png
```

`local-assets` 目录已被 .gitignore 保护,**永远不会被提交到仓库**。

## 第三步:上传(一次性)

在项目目录打开终端,把四个值换成自己的(部署时配置过的那套 Supabase 信息;共享密码即私密空间密码):

```bash
VITE_SUPABASE_URL=https://xxxx.supabase.co \
VITE_SUPABASE_ANON_KEY=eyJ... \
VITE_SHARED_AUTH_EMAIL=xxxx@xxxx.com \
VITE_PRIVATE_SPACE_PATH=xxxx \
AVATAR_SHARED_PASSWORD=你们的共享密码 \
node scripts/upload-avatars.mjs local-assets/l-avatar.png local-assets/w-avatar.png
```

看到两条 `✓ 已上传` 即成功。**打开私密空间刷新页面**,顶栏身份按钮和首页「海蓝色的 L / 粉色的 W」角色卡就会显示头像。

(Git Bash / macOS / Linux 直接用上面的命令;Windows PowerShell 需要改成 `$env:VITE_SUPABASE_URL="...";` 逐行设置后再运行 `node scripts/upload-avatars.mjs ...`。)

## 想换头像?

重新生成 → 再跑一次上传脚本即可(同名覆盖)。头像以签名链接的方式加载,只在登录后的私密空间有效,链接一小时自动过期,不会泄露。
